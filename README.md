# Senior Software Engineer | Computer Vision Systems | Python & Rust

I build computer-vision and event-processing systems, with experience spanning
image capture, recognition, concurrent processing, backend services, desktop
interfaces, and deployment.

My main interest is how these systems fit together: defining clear interfaces,
managing state and concurrency, and making software easier to test and evolve.
I work primarily with Python and Rust and am deepening my practice through
continued study of software architecture and system design.

I’m interested in hands-on technical leadership roles in scientific and industrial
computer vision. My interest in the natural sciences draws me toward software that
helps people observe, measure, and interact with the physical world.
